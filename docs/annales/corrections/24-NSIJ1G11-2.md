<div class="circle-ol" markdown>

1. En notation décimale pointée, le masque du réseau L2 s'écrit `/16 = 11111111.11111111.0.0 = v`.

2. L'adresse de L2 est `176.16.8.8 & 255.255.0.0 = 176.16.0.0`.

3. L'adresse de diffusion de L2 est la dernière adresse possible, à savoir `176.16.255.255`.

4. Puisque que le numéro d'hôte est codé sur 16 bits, le nombre maximum de machines pouvant être connectées à ce réseau est de $2^{16} - 2 = 65534$.

5. Le message suit le chemin **L1 → A → H → D → L2**

6. Il existe deux routes possibles, **L1 → A → B → C → D → L2** ou **L1 → A → H → C → D → L2**.

7. Pour la route L1 → A → B → C → D → L2 : 
   
    | Routeur | Réseau destinataire |  Passerelle   |   Interface   |
    | :-----: | :-----------------: | :-----------: | :-----------: |
    |    A    |         L2          | `193.55.24.2` | `193.55.24.1` |

    Pour la route L1 → A → H → C → D → L2 : 

    | Routeur | Réseau destinataire |  Passerelle   |  Interface   |
    | :-----: | :-----------------: | :-----------: | :----------: |
    |    H    |         L2          | `53.10.10.10` | `53.10.10.9` |

8. 
| Bande passante |              Coût              |
| :------------: | :----------------------------: |
|  100 Mbits/s   | $10^9 / (100 \cdot 10^6) = 10$ |
|   1 Gbits/s    |  $10^9 / (1 \cdot 10^9) = 1$   |
|   10 Gbits/s   | $10^9 / (10 \cdot 10^9) = 0.1$ |

9. Le message suivra la route **L1 → A → G → F → E → D → L2** de coût **1.3**.
    
10.  Le message suivra la route **L1 → A → H → F → E → D → L2** de coût **2.2**.
