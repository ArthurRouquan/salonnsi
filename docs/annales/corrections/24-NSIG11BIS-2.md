title: 24-NSIG11BIS-2
---

<div class="circle-ol" markdown>

1. Seul le troisième octet des adresses IP permet de déterminer leur réseau :

    |     Adresse     | 3<sup>e</sup> octet | `&255`  | `&254`</br>`=255–1` | `&248`</br>`= 255–1–2–4` |  Réseau   |
    | :-------------: | ------------------- | :-----: | :-----------------: | :----------------------: | :-------: |
    | `192.168.129.3` | `129=128+1`         |   129   |       **128**       |           128            |   **D**   |
    | `192.168.194.2` | `194=128+64+2`      |   194   |         194         |           192            | **Aucun** |
    | `192.168.192.7` | `192=128+64`        | **192** |         192         |           192            |   **B**   |
    | `192.168.72.25` | `72=64+8`           |   72    |         72          |            72            | **Aucun** |

2.  * Le réseau A réserve 11 bits pour le numéro d'hôte, donc on peut y connecter \(2^{11} - 2 = \boxed{2046}\) machines.  
    * Le réseau D réserve 9 bits pour le numéro d'hôte, donc on peut y connecter \(2^9 - 2 = \boxed{510}\) machines.

3.  * R1 dans A : `192.168.64.1`
    * R3 dans B : `192.168.192.2`

4. La table de routage de R2 est :

    | Réseau              | Masque          | Passerelle           | Sauts |
    | :------------------ | :-------------- | :------------------- | :---: |
    | `192.168. 64.0` (A) | `255.255.248.0` | `0.0.0.0`            |   0   |
    | `192.168.192.0` (B) | `255.255.255.0` | `0.0.0.0`            |   0   |
    | `192.168.193.0` (C) | `255.255.255.0` | `192.168.192.2` (R3) |   1   |
    | `192.168.128.0` (D) | `255.255.254.0` | `192.168. 64.1` (R1) |   1   |

5. La table de routage de R4 devient :

    | Réseau              | Masque          | Passerelle      | Sauts |
    | :------------------ | :-------------- | :-------------- | :---: |
    | `192.168.193.0` (C) | `255.255.255.0` | `0.0.0.0`       |   0   |
    | `192.168.128.0` (D) | `255.255.254.0` | `0.0.0.0`       |   0   |
    | `192.168. 64.0` (A) | `255.255.248.0` | `192.168.128.1` |   1   |
    | `192.168.192.0` (B) | `255.255.255.0` | `192.168.193.1` |   1   |

6.  * `192.168.193.17` (machine sur le réseau C) : **R2 → R3**
    * `192.168.129.17` (machine sur le réseau D) : **R2 → R1**
    * `192.168. 65.17` (machine sur le réseau A) : **R2**
    * `192.168.192.17` (machine sur le réseau B) : Aucun routeur traversés

7.  * Réseau D1 d'adresse de réseau `192.168.128.0` et de masque `255.255.255.0`
    * Réseau D2 d'adresse de réseau `192.168.129.0` et de masque `255.255.255.0`

8. La table de routage R1 :

    | Réseau               | Masque          | Passerelle          | Sauts |
    | :------------------- | :-------------- | :------------------ | :---: |
    | `192.168. 64.0` (A)  | `255.255.248.0` | `0.0.0.0`           |   0   |
    | `192.168.192.0` (B)  | `255.255.255.0` | `192.168.64.2` (R2) |   1   |
    | `192.168.193.0` (C)  | `255.255.255.0` | `192.168.64.2` (R2) |   2   |
    | `192.168.128.0` (D1) | `255.255.255.0` | `0.0.0.0`           |   0   |
    | `192.168.128.0` (D2) | `255.255.255.0` | `192.168.64.2` (R2) |   3   |

    La table de routage R4 :

    | Réseau               | Masque          | Passerelle           | Sauts |
    | :------------------- | :-------------- | :------------------- | :---: |
    | `192.168. 64.0` (A)  | `255.255.248.0` | `192.168.193.1` (R3) |   2   |
    | `192.168.192.0` (B)  | `255.255.255.0` | `192.168.193.1` (R3) |   1   |
    | `192.168.193.0` (C)  | `255.255.255.0` | `0.0.0.0`            |   0   |
    | `192.168.128.0` (D1) | `255.255.255.0` | `192.168.193.1` (R3) |   3   |
    | `192.168.128.0` (D2) | `255.255.255.0` | `0.0.0.0`            |   0   |

    Il faut bien noter qu'une fois le réseau D découpé en deux, R1 et R4 ne sont plus directement connectés.
