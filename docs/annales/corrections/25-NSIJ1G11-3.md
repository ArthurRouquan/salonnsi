```python hl_lines="3 4 7"
def rechercher(self, numero):
    if self.est_vide():
        return None
    if numero == self.num_serie:
        return self
    elif numero < self.num_serie:
        return self.gauche.rechercher(numero)
    else:
        return self.droit.rechercher(numero)
```
