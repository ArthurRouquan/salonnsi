```python
def note(cop, corr):
    total = 0
    for i in range(len(cop)):
        if cop[i] == corr[i]:
            total += 1
    return total
```

```python
def note_paquet(p, corr):
    return {nom: note(cop, corr) for nom, cop in p.items()}
```

    ```python
    def note_paquet(p, corr):

    ```

```python hl_lines="7 9 12 14"
def renote_express2(copcorr):
    gauche = 0
    droite = len(copcorr)
    while droite - gauche > 1:
        milieu = (gauche + droite) // 2
        if copcorr[milieu]:
            gauche = milieu
        else:
            droite = milieu

    if copcorr[gauche]:
        return droite
    else:
        return gauche
```

1.  En notant $n$ la taille de la liste, la fonction `renote_express` qui repose sur un simple parcours de la liste est de complexité en temps **linéaire** $O(n)$ et `renote_express2` qui repose sur une recherche dichotomique est de complexité en temps **logarithmique** $O(\log n)$.
